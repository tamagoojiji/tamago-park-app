3. なぜ @ の 5.182.33.65 を削除するのか

現在 @（ルートドメイン）に Aレコードが5つ登録されています：

  • GitHub Pages用 × 4（185.199.108〜111.153）
  • VPS用 × 1（5.182.33.65）

DNSは複数のAレコードがある場合、ランダムにどれか1つを返します。そのため約5回に1回、アクセスがVPSに飛ばされます。VPSにはパーク攻略アプリが置かれていないため、エラーや意図しないページが表示されてしまいます。

【削除前（現状）】 tamago-ai-world.com → GitHub Pages（80%） → VPS（20%）← アプリがないのでエラーになる 【削除後（正常）】 tamago-ai-world.com → GitHub Pages（100%）← 常にパーク攻略が表示される

4. chat.tamago-ai-world.com への影響

影響なし。AIbotは今まで通り動きます。

@（ルートドメイン）と chat（サブドメイン）は完全に独立した別のレコードです。@ のAレコードをいくら変更・削除しても、chat のAレコードには一切影響しません。

@ (ルートドメイン) ──→ GitHub Pages ← 今回変更する部分 chat (サブドメイン) ──→ VPS 5.182.33.65 ← 一切触らない mail ──→ メールサーバー ← 一切触らない

5. 作業手順

  1. ConoHa DNS管理画面を開く
  2. @ の 5.182.33.65 のAレコードを削除する（他の4つのAレコードは残す）
  3. GitHub側でカスタムドメイン設定を行う（こちらで対応）
  4. DNS反映を待つ（最大数時間〜24時間）
  5. tamago-ai-world.com にアクセスしてパーク攻略アプリが表示されることを確認
  6. chat.tamago-ai-world.com にアクセスしてAIbotが正常に動くことを確認
注意: chat のAレコード（5.182.33.65）は絶対に削除しないでください。AIbotが動かなくなります。削除するのは @ の 5.182.33.65 のみです。

6. www について（要確認）

www.tamago-ai-world.com も現在 VPS（5.182.33.65）を指しています。

  • VPSで www 経由のサービスを使っていない場合 → 削除してOK
  • 将来 www.tamago-ai-world.com でもパーク攻略を表示したい場合 → CNAME www → tamagoojiji.github.io に変更
